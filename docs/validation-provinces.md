# 中国大陆默认省级玩法验证记录

日期：2026-11-08。代码及ZIP已完成开发验证；平台模拟器、Android、iOS和Chrome61设备验收待完成。

## 行为与兼容

- 全部地区默认猜大陆31个省级行政区，使用原有regions轮廓运行时派生，不新增或修改原始几何。题目随机、不重复，同级四选一，答对1分、错3次或答完结束，最高31分。
- 首页示例为河北省；每次从首页开始恢复全部地区。地区选择仅修改准备草稿；结算重玩沿用上一局冻结设置，查看榜单不影响重玩。
- 指定安徽省仍为16道地级题，北京市仍为16道区题；31地区下级题库共418题保持不变。
- 省级题面统一显示中国大陆、这是哪个省级行政区，不含父地区提示或位置小图；指定地区保留位置小图。自治区正式名称可换行。
- 会话规则版本3；地图题库版本不变。省级最佳使用cities:provinces，旧cities:all保留但不参与新玩法。存储容器保持历史键，国家和指定地区成绩继续有效。
- 活跃榜位为1/2/3/5；省级使用china-provinces对应board5。旧board4停止读取和提交；指定地区仅保存本地区最佳。
