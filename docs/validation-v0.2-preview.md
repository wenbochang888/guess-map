# v0.2 实施与验证报告

日期：2026-11-07。**本次为功能预览交付，全国地图扩充尚未完成，不是全国完整版。** 旧首版结果归档在`validation-v0.1.md`，不能拿旧成绩替代本次回归。

## 已实现

- 国家简单/中等/困难，默认中等；累进目标池分别23/46/60题，分档干扰项。四选一、无倒计时、答对一分、累计三错结束均保留。
- 31省区市目录、可搜索地区面板、默认全部、按父地区筛题；目前有数据的十省仍仅各4道精选题。缺失地区明确说明并禁用开始，不混入别省。
- 会话冻结难度/地区、规则/题库版本、个人纪录键及榜位；判分使用实体ID，支持行政重名消歧。
- 个人最佳按三档国家、中国全部和各省级地区隔离；旧v1不误迁移。
- 四榜显式映射：1简单、2中等、3困难、4中国全部。缓存和失效按榜位隔离；指定地区零提交，当前不完整中国预览也零提交全域榜。
- 首页与结算榜单入口、有权限才显示；榜单浏览不改变本局或重玩设置。
- 结算左上直接回首页；中途退出仍确认；已完成局的保存和提交不因立即离开结果页而丢失。
- 正常结算先成绩后关注卡；未关注才自动提示，点击才拉起平台确认；已关注/本人/中途退出不弹，从榜单返回同局不重弹。
- 关注原始Promise互斥，超过五秒、关闭卡、切页或重玩不误解锁；区分取消、频控、前一流程未结束与真实成功。未知关系非模态降级，不伪报成功。
- 共享弹窗、Safari焦点返回、键盘/Escape、触摸尺寸、减少动态效果和短屏布局。
- 全国已审核数据的导入器、逐地区覆盖报告、缺数据正式发布门禁。

## 尚未完成的范围

**完整全国地级行政区与四个直辖市下辖区县的实际题库，尚未完成。**

- 现有HDX数据中北京为单个市级要素，无各区轮廓。
- 另核查geoBoundaries县级数据，北京城区合并为旧要素，并有历史县名，不能简单改名拆成现行各区。
- 已核验许可的实际产品仍只有原十省40题，10个地区为样本、21个地区缺题；这不是31地区完整覆盖。
- 未引入许可不明GeoJSON、非商业受限数据或合成矩形来凑数。
- `scripts/import-china.py`已实现完整目录/许可证据/父子层级/几何/哈希/可复现导入流程，但不代表已经获得可用数据。合成几何只在隔离的测试目录验证程序，未进入产品。
- 国家候选编排是初稿，尚无真实目标用户的难度正确率或留存实验。

后续数据要求、已查来源和导入格式：`docs/china-data-import.md`。`npm run data:check`当前退出1，按预期阻止误发布；不是把失败当作成功。全国数据未补齐前不生成新版正式包，也不宣称计划全部完成。
