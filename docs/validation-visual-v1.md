# 视觉与交互升级验证（visual-v1，2026-11-10）

范围：只改前端表现层。题库、计分、榜单、关注、存储、审图合规逻辑未改动；`src/game/`、`src/platform/` 零修改。

## 已实现

- **品牌统一为「猜地图」**：`BrandMark` 折叠地图+陶土红问号（按 `资料/1.png` 重绘的内联 SVG）；页面标题、meta、theme-color 同步。
- **设计系统**（`src/styles/tokens.css`）：颜色、字号阶梯、间距、圆角、阴影、动效时长/缓动全部令牌化。字号由 32 种收敛为 11 档（11/12/14/16/20/24/32/44/56/72/96），旧版有 30 处 <11px，现为 0；源码与产物 CSS 中没有一处裸 px 字号（门禁强制）。
- **海报风**：米黄纸+颗粒（内联 SVG 噪点，纯静态）、牛皮纸三折地图卡、切角分段控件、粗体大标题（系统字体最粗到 Semibold，用 0.6px 描边补字重）、陶土红手绘下划线。装饰性英文全部删除。
- **流程**：删除「准备开始」面板。首页中国模式显示“游玩范围”入口，点“更换”打开地区面板，选中即生效；“开始猜”一步开局，与国家模式一致。
- **答题页**：顶栏「第 N / 总数」+ 细进度条；重复 4 次的上下文信息收敛为一行；答对「+1」上飘、卡片描边闪光、勾号描边绘制；答错选项轻摇、心形弹碎、正确名称标签出现在地图卡左上角、「下一题」按钮内 3 秒填充线；连对 ≥3 出现「连对 ×N」徽标（纯 UI 状态，不影响计分）。
- **结算页**：得分环（CSS 描边动画）、称号（初见轮廓 / 渐入佳境 / 认路达人 / 活地图）、「没认出的」文字回顾（不绘制地图，合规）。
- **排行榜**：墨绿「我的排名」卡、前三名放大高亮、行依次入场、周期下划线滑动。
- **弹窗**：说明弹窗分「玩法 / 地图与数据来源 / 记录与排行榜」三节，来源文字原样保留。
- **结构**：`App.vue` 拆出 `src/screens/` 四个展示组件，状态与计时器仍在 `App.vue`；样式拆为 7 个模块，旧 `main.css` 已删除。

## 与计划不一致之处（如实记录）

| 计划 | 实际 | 原因 |
|---|---|---|
| 结算分数 0→N 数字滚动（`ScoreTicker`） | 改为 `ScoreRing` 描边动画 + 数字弹入；数字文本始终是最终得分 | 现有 e2e 大量使用 `page.clock` 假时钟，JS 驱动的滚动会卡在 0；纯 CSS 更稳 |
| 打包思源黑体子集 | **未做**，用系统字体 + 描边补字重 | 需联网下载字体并安装 fonttools，未取得你的确认；计划本就标为可选 |
| 屏幕切换用 `<Transition>` | 改为各页面根节点的 CSS 入场动画 | `<Transition>` 让离场页面多停留约 2 帧，DOM 里同时存在两份内容，导致 e2e 严格模式冲突，也不利于无障碍 |
| 回首页后记住上次地区 | **保持原行为**：回首页重置为全部地区 | 该行为有现成 e2e 覆盖，且属计划里待你确认的风险点，未经确认不改 |
| 答错时问号换成正确名称（卡片底部） | 名称标签放在卡片左上角 | 放顶部/底部会遮住轮廓端点，实测左上角遮挡最少 |
